Onboarding e Localização (Prioridade)Ação: Usuário abre o App/Web-App Syncuria.Front-end: A primeira tela (após login/cadastro) deve pedir a localização.Opção A (Melhor): Solicitar permissão de GPS (Permitir que a Syncuria use sua localização?).Opção B (Manual): Caixa de input destacada (Digite seu CEP ou Endereço para iniciar a busca).Lógica: Sem a localização definida, o sistema não mostra resultados, garantindo que a busca seja sempre relevante e focada na Praticidade e Urência da entrega/serviço.2.
